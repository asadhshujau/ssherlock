# 0001 — gpui for all UI

**Status:** accepted · 2026-11-10

## Context
SSHerlock is a desktop app whose core is a terminal that must redraw large grids at display
refresh rate, alongside ordinary forms and lists. We want one Rust codebase for macOS and Linux,
no web view, and no `unsafe` in our own code.

## Decision
Use [gpui](https://crates.io/crates/gpui), Zed's GPU-accelerated UI framework, for everything on
screen, pinned exactly (`=0.2.2`). Only the `ssherlock` and `ssherlock-ui` crates depend on it.

## Consequences
- GPU rendering (Metal on macOS, Vulkan on Linux) handles terminal-sized redraws, and Zed shows a
  terminal built on gpui + `alacritty_terminal` works well.
- gpui's API changes between minor versions, so upgrades are deliberate PRs, not `cargo update`.
- It has no widget library: buttons, inputs, lists and modals are ours to build in
  `ssherlock-ui/src/components/`.
- Linux needs native libraries at build time (README *Development setup*), and on GNOME/Wayland
  we draw our own window decorations (`window_frame.rs`).
- gpui's dependency tree is large; `deny.toml` carries a few licence exceptions for it.
